# Nordic Empire

Official nation site for the **Nordic Empire** on [DiplomaticaMC](https://diplomaticamc.com/).

This is a static site covering the realm’s towns, Constitution, history, Nordic Times gazette, and how to join. Heimstad is the capital; Stavanger is the main residential town. Other member towns include Nordic_island and Gardsbruk.

## View the site

**Live site:** [https://thegoldencowz.github.io/NordicEmpire/](https://thegoldencowz.github.io/NordicEmpire/)

The site is hosted with GitHub Pages and deploys from `main` via [.github/workflows/static.yml](.github/workflows/static.yml).

## Local preview

Open `index.html` in a browser, or serve the repo root with any static file server:

```bash
npx serve .
```

## Stack

- HTML, CSS, and vanilla JavaScript
- Single-page navigation via hash routes (`#home`, `#towns/stavanger`, etc.)
